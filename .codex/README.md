# Voice Lab Codex 文档入口

本目录存放按需规则；常驻规则在上级 `AGENTS.md`，产品/部署行为以根或模块 README 为准。

- `workflows.md`：故障排查、逻辑审查、模型/迁移验证和 Git 流程。
- `docs/code-review.md`：FastAPI、SQLite、队列、模型、文件和前端的 CR 清单。
- `docs/doc-writing.md`：文档分层、记录边界和命名。
- `skills/`：仅用户明确要求时运行的全量 Bug/性能扫描。

先读 `AGENTS.md`，再按任务读取目标 README 和相关文档；不要无边界扫描，规则只保留一个权威来源。
