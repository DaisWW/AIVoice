# 发音标记说明

本工具只运行所选模型的声音克隆，不执行延音、重音、变调、降噪、EQ、压缩、混响或响度后期。

虫语不属于中文时，在发音前加 `raw:`（也支持 `ipa:` / `phoneme:`），例如：

```text
虫语角色 | raw: t͡ʃa-ʀ——ɬa↗
```

原音素会原样保留，不会强制替换成汉字。GPT-SoVITS 的中文文本前端不支持该模式；请改用支持原音素的模型，或上传真人表演音频走声音转换流程。

选择 CosyVoice3 时，普通音节直接转换为连续的原生音素：`ra-la` 对应 `[r][a][l][a]`，保留辅音区别。连字符、空白和延音横杠不会变成词间空格；逗号、省略号等停顿标点保留。大写音节使用模型重音标记。显式原生输入示例为 `raw: [m][o][l][a][n][a]`；raw 输入中的空格会原样保留。模型只支持它训练过的音素；原样保留的任意 IPA、自定义符号或普通字母不等于能准确发音。延音数量仍作为元数据保存，不保证精确时长。

| 写法 | 克隆阶段的处理 |
| --- | --- |
| `shu-la` | 按两个拟声音节生成 |
| `shu—la` | 横杠保留在结果页，送入模型前移除 |
| `shu———la` | 连续数量保留，供外部后期判断延音长度 |
| `GU-la` | CosyVoice3 使用模型重音标记；其他模型保留为指导信息 |
| `la↗` / `la↘` | 转成问句或陈述句标点，可能影响模型尾音 |

- 英文短横线 `-` 只分隔音节。
- 中文长横杠 `—`（U+2014）表示建议持续发音；连续数量越多，建议延音越长。
- 系统兼容 `–`、`―`、`－`，新台本建议统一使用 `—`。
- 单个音节最多标记 6 格延音。
- `……` 可提示停顿、换气或减弱，但模型的实际表现存在随机性。
- 页面会原样展示发音标记，下载包中的 `台本与发音.json` 也会保留这些信息。

建议外部后期按每格约 `80-180 ms` 处理；这是剪辑参考值，不会在本工具内自动应用。

示例：

```text
陌生人，可否听我讲一段故事 | mo——la，na？↗
你肯定知道我爷爷的故事 | GU-la……gu-la-da。↘
嗯——……ha。↘
```
