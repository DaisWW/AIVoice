# 发音标记说明

本工具只运行 GPT-SoVITS 声音克隆，不执行延音、重音、变调、降噪、EQ、压缩、混响或响度后期。

| 写法 | 克隆阶段的处理 |
| --- | --- |
| `shu-la` | 按两个拟声音节生成 |
| `shu—la` | 横杠保留在结果页，送入模型前移除 |
| `shu———la` | 连续数量保留，供外部后期判断延音长度 |
| `GU-la` | 大写重音信息保留，供录音指导或外部后期参考 |
| `la↗` / `la↘` | 转成问句或陈述句标点，可能影响模型尾音 |

- 英文短横线 `-` 只分隔音节。
- 中文长横杠 `—`（U+2014）表示建议持续发音；连续数量越多，建议延音越长。
- 系统兼容 `–`、`―`、`－`，新台本建议统一使用 `—`。
- 单个音节最多标记 6 格延音。
- `……` 可提示停顿、换气或减弱，但 GPT-SoVITS 的实际表现存在随机性。
- 页面会原样展示发音标记，下载包中的 `台本与发音.json` 也会保留这些信息。

建议外部后期按每格约 `80-180 ms` 处理；这是剪辑参考值，不会在本工具内自动应用。

示例：

```text
陌生人，可否听我讲一段故事 | mo——la，na？↗
你肯定知道我爷爷的故事 | GU-la……gu-la-da。↘
嗯——……ha。↘
```
